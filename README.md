# Video Platform Back End

This is a video platform app to upload videos using imagekit and Django

## Tech Used
- Django
- Django Rest Framework
- Imagekit
- Docker
- UV

## How to run it

The project is setup to run using Docker to make it easier to run for everybody.

First check if your machine has docker installed by opening a console and running this command:

``` BASH
docker --version
```

If there is an error just follow the [Docker documentation](https://www.docker.com/products/docker-desktop/) to install docker desktop in your machine


When you have Docker Desktop installed just clone the repository, open a console inside the root of the project and run:

``` BASH
docker compose up -d
```
